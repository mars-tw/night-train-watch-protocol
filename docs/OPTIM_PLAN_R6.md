# 手機版面與細緻像素風重製

日期：2026-10-03。使用者指出手機跑版、啟動首頁人物亂動，以及美術不符合原先四張參考。前輪的平滑插畫不可當成細緻像素風已完成。版本目標 v2.3.0，沿用開源更新與 Pages 授權。

| 面向 | 修正內容 | 可驗收結果 |
| --- | --- | --- |
| 美術 | 對照四張參考重製暖色車廂、生活小物與冷窗像素層次；保留舊素材 | 新原創 raster、清晰像素群與階梯輪廓、無模糊照片質感／SVG；來源與實際工具記錄 |
| 按鈕 | 修正手機 viewport／安全區與浮層 | 320／360／375／390／393／430 寬度、低屏、字級與旋轉，主控制可見可點 ≥44px |
| 選單 | 安定首頁、一套版面，不靠多層位移補丁 | 首頁圖像完整構圖；人物不抖動、不跨格瞬移；離線狀態有固定布局位置 |
| 人物 | 首頁為完整像素場景，遊戲動作有固定角色錨點 | 一位 A-07；角色臉、頭、身體與床的連續性，主選單時間前後穩定 |
| 場景／地圖 | 五車廂同一像素美術語言；保留實際機能與熱區 | 主床位置與設備對齊、車窗外威脅與室內安全感、地圖／來源可追溯 |
| 技能／機能 | 場景熱區、成本與任務回歸 | 不靠存檔注入，取消不扣、成功只扣一次、五項教學正常 |
| 角色／道具品質 | 新圖來源經既有 Blender 資產管線處理與開源授權記錄 | 整体畫面逐張視覺檢查與原參考對照；不只以測試數量稱畫風達標 |
| 動作／效能 | 安定首頁，遊戲保留真畫格，低動態設定有效 | 首頁無人物漂移；遊戲真來源畫格；完整快取、斷網與三跑 p95 ≤18ms |

分工：主代理負責參考、圖像生成、整合、最終視覺判斷與發布；手機工作單負責 viewport／選單／離線狀態布局；renderer 工作單負責首頁靜態構圖及像素取樣／角色錨點；資產工作單負責生成後 Blender 處理、版控來源與新 manifest。先保存 before，再比較新畫面，獨立覆核後執行 CI／Pages 及公開網址檢查。手機尺寸測試不冒稱實體裝置測試。

本機驗收完成：40 檔／341 項測試、兩套瀏覽器各 24 組真實設定矩陣、15 組遊戲控制與自然兩夜流程、25 項像素／固定首頁驗證、38 項圖片回歸及完整離線更新通過。三跑中位 p95 均 16.7ms，桌面一次 33.3ms 原始 outlier 保留。獨立上下文覆核 PASS。[完整結果與限制](CODEX_RESPONSE_V23.md)。接續發布 CI／Pages 與公開版本驗證。
