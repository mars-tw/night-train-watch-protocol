# 圖片動畫美術更新

日期：2026-10-02。使用者要求漂亮的圖片動畫，移除粗糙 SVG 與程式繪製物件，並更新開源與公開遊戲。分支：`codex/raster-animation-v21`。

| 面向 | 本輪工作 | 驗收 |
| --- | --- | --- |
| 美術 | 同畫風的圖片圖示、道具、環境逐幀、紙本地圖；保留精緻五廂背景 | 真實生成來源、Blender 處理、runtime 接線；可見畫面沒有 SVG |
| 按鈕 | 圖片圖示替換字母／幾何符號，保留清楚文字與48px熱區 | 五視口、三字級、中心點可達 |
| 選單 | 減少遮住車廂的深色大框，紙張／木作的圖像介面 | 關閉、返回、確認可達，不影響原控制契約 |
| 人物 | A-07 真姿勢與威脅圖集持續使用，修正過重遮色及晃動 | 人臉及剪影清楚，64px仍可辨識 |
| 地圖／場景 | 紙本路線／技術圖取代 SVG 線條；設備與裝飾使用圖片 | 三线分支狀態仍可讀，操作不變 |
| 技能／機能 | 道具圖片與環境真幀回饋，成本與領獎邏輯保持權威 | 取消、保存、反制回歸全綠 |
| 角色／道具品質 | 圖片的明度、飽和度與alpha，記錄各項實測 | 人物／道具與背景分開檢查，不冒稱模型識別 |
| 動作流暢度 | 蒸氣／燈火／葉片等不同畫格；停止生硬物件幾何描畫 | reduced-motion與暫停尊重設定，三跑p95≤18ms |

來源研究沿用 `reboot-v2/ART_STUDY.md` 的開源美術技法並追加本輪應用：材質先於符號、固定局部光源、少量環境動畫與完整姿勢幀。新素材由內建圖像工具產生，再經 Blender 轉為可用圖集；沒有工具提供的模型識別就保持 null。

分工：主代理產生素材與最終發布；獨立上下文負責 UI 圖片接線、renderer 圖片化、素材管線與文件。八大項與本輪有關的驗收均記錄實際證據。執行 `npm run check`、UI 可達性、離線、三視口與 before/after、效能及秘密掃描；獨立覆核後才合併與部署。
