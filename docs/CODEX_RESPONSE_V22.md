# v2.2.0 更新驗收

本輪完成首夜指引、離線狀態、A-07 無損分段載入與宣傳頁操作。三條七夜路線、56 項任務、存檔 schema 6 與權威資源規則沿用既有遊戲。

## 玩家會看到的改變

- R01 前兩日以實際任務進度提示下一步。免費觀察不扣 AP；配電教學先關閉再恢復 M003，M001 防護板保持開啟；播種先預覽，可取消；夜間標示反制名稱及實際成本。
- 整備提示保留任務入口。玩家釘選任務後，指引讓位給自己的目標；取消釘選便恢復指引。低屏收起補充文字，但無障礙說明仍保留。
- 主選單顯示離線準備、完整就緒、失敗重試及更新狀態。下載不完整時不宣稱可離線，保留上一版快取與存檔。新 worker 接手資料請求後，已開啟的遊戲不被強制重載。
- A-07 七段圖片依動作載入，保留 52 個真姿勢、原座標、尺寸、透明度與動畫時鐘。主選單固定使用睡眠動作，帶有既有旅程時也不會因動作未載入而消失。
- 宣傳頁支援橫／直式切換與六個玩法章節。切換保留播放時間及播放／暫停狀態；手機首次開啟預設直式。影片仍標示為 v2.1 實際遊玩錄影，這輪沒有更換已接受的影片內容。

## 品質取捨與修正

q98／q100 有損圖集未通過可見及不透明像素的細節門檻，因此撤回。正式版本採既有無損 WebP 的精確列裁切，沒有新增生成模型，原始 PNG、Blender 成果及完整圖集都保留。[完整邊界報告](reboot-v22/ATLAS_RUNTIME_V22.md)包含被拒絕的數據。

初版提示與作物鈕碰撞已修正；離線浮層曾把低屏選單鈕推出視口，也已以所有按鈕實際中心命中檢查修正。稽核腳本改為等待實際 DOM 更新，不再假設保存於 100ms 內完成。增加提示後，重複的切廂動作名稱改以車廂導覽區定位。

文案校正例：「新版已準備好，下次開啟時套用」改為「離線資料已更新，下次開啟載入新版遊戲」，明確區分新快取已接手與目前頁面仍執行原本程式。

`git diff --check` 與來源秘密掃描通過。獨立覆核使用另一個相同模型的上下文，[覆核紀錄](evidence/v22/independent-review.md)列出範圍與限制；沒有把它稱為不同模型驗證。公開版本由 GitHub CI／Pages 再建置，公開網址須在部署完成後另外驗證。
