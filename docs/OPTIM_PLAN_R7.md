# 首頁動畫邊界修正

日期：2026-10-05。使用者仍看到首頁動畫／影格跑出框架。本輪為 v2.3.1 小幅修正，先檢查使用中的公開頁面、快取版本及切畫面時的 CSS／Canvas 狀態，不能把靜止截圖當完整播放證據。

| 面向 | 驗收 |
| --- | --- |
| 美術、人物、場景 | 沿用已完成的像素圖，不重畫；首頁不可顯示角色圖集或殘留遊戲影格 |
| 按鈕、選單 | 第一載入、快速切廂返回、背景恢復及旋轉，框架與控制完整可見可點 |
| 技能／資源 | 繼續與重新整理保留同一旅程；不注入存檔，不清掉既有資料 |
| 角色／道具品質 | 核對來源與 source rectangle，避免相鄰 atlas 格溢入 |
| 動作 | 首頁動畫確實停用，清理過渡 class／transform；逐時間樣本確認整個圖像邊界 |
| 離線與部署 | 確認舊 worker／新 worker 的實際版本；完整 CI、PWA 與公開網址驗證 |

主線負責修正與發布；獨立工作單唯讀檢查原因與最終差異。保存失敗／修正證據與有界回歸，沿用既有七夜故事及 56 項任務。測試使用桌面 Chromium／WebKit 視口，不冒稱實體手機。

本輪完成記錄見 [v2.3.1 驗收](CODEX_RESPONSE_V231.md)。新的固定畫面稽核涵蓋實際導航與第一夜結算，兩個瀏覽器各 17 項通過；旋轉與背景恢復沿用 v2.3 已有覆蓋，沒有聲稱本輪重新測量所有裝置情境。
