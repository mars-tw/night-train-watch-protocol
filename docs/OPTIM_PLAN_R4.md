# 開源首頁宣傳影片

日期：2026-10-03。使用者已澄清，本輪是更新開源首頁並錄製宣傳影片，沒有商店上架工作。分支`codex/promo-film-v211`。

| 面向 | 本輪工作 | 驗收 |
| --- | --- | --- |
| 美術 | 錄製v2.1真實圖片動畫、製作影片封面 | 不以mockup或動畫生成畫面冒充遊戲 |
| 按鈕 | README封面可點、播放頁控制可達 | 手機／桌機實際點擊、播放成功 |
| 選單 | 影片頁保留遊玩與返回開源入口 | 無死路、不依賴有聲autoplay |
| 人物 | 影片顯示A-07及守夜威脅真畫格 | 來源錄影時間線可追溯 |
| 地圖／場景 | 展示五廂、紙本路線與停站探索 | 完全由正常UI操作錄製 |
| 技能／機能 | 顯示實際任務、照護、生產與反制 | 不注入資源、phase或checkpoint |
| 角色／道具品質 | 字幕不遮主要畫面、H.264 MP4清晰 | 分辨率／幀率／音訊／檔案大小核對 |
| 動作流暢 | 剪成短版宣傳影片、保留真實動畫 | 完整decode、抽幀、字幕與地端終審 |

主代理負責錄影與剪輯，獨立上下文負責影片播放頁／README接線及技術覆核。影片內容終審依core-rules交地端模型；不以雲端代理代替。原始錄影留在ignored的output，成品與封面、播放頁、時間線／QA記錄公開，影片不加入PWA首次快取。

完成後更新README、版本與Release附件；先獨立覆核，再合併及驗證Pages的實际播放。
