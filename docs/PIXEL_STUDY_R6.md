# 四張參考的像素美術對照

參考為使用者提供的手機截圖，只用於本機風格對照，廣告標誌、社群控制及原圖不進開源。

視覺方向：狹長車廂像一個有人生活的小家；室內暖琥珀、奶油毛毯、木作與橄欖金屬，窗外冷藍灰與遠處威脅。形體由清楚的像素群、階梯剪影、二至五階材質明度形成；書脊、瓶罐、鉛筆、電線、葉片、布料毛邊要可辨，不能用雜訊假裝細節。角色為簡潔有辨識度的像素臉，安穩躺在床上，不能疊成與房間不一致的平滑大頭。

本輪新圖以此構圖語言重製。首頁用完整、固定的人物與床一體場景；遊戲場景保留各廂實際用途和相同床錨點，動作與背景分層。

技術參考：

- [Aseprite Animation](https://www.aseprite.org/docs/animation/)：用實際畫格與範圍形成動作，檢查前後格連續性；本輪不以整張圖晃動代替姿勢。
- [Aseprite Sprite sheets](https://www.aseprite.org/docs/sprite-sheet/)：圖集有明確座標、大小及間隔，本輪保持逐格坐標並避免自動裁切造成角色錨點漂移。

實際應用：新的細節來自圖片重製，nearest 只負責保留像素邊界，不能把平滑插畫換個 CSS 就稱為像素重製。色彩設定由新圖本身決定；主廂與人物逐張檢查，再由 Blender 以中性色彩及像素取樣輸出。工具未透露模型 slug 時記 null，不宣稱已驗證特定模型。
